Aegis local test pages

Load the unpacked extension, open the service worker console (chrome://extensions → Inspect views), then click through these:

  • /clean.html — plain page, should score 0, no banner.
  • /password-http.html — a password field on plain HTTP. Should trigger the password_http reason.
  • /brand-mismatch.html — a "PayPal" login page on a non-PayPal domain. Should trigger brand_title_mismatch (plus password_http).
  • /redirect/start — a 4-hop server-side (302) redirect chain landing on /redirect/final.html. Should trigger chain_length.

Not testable on localhost: lookalike-domain, punycode, and combosquat checks need a real registrable domain (e.g. paypa1.com) to compare against the brand list — they won't fire against localhost. To exercise those paths, run the unit tests instead: npm test.
